The Problem

Challenges are organized in chats and get lost along the way

Groups of friends start habit challenges, but evidence, votes, and points become scattered among messages. Over time, the challenge is abandoned because there is no proper follow-up or group support.

Target User

University students who create habit challenges with friends or classmates in small groups.

Need

Centralize the active challenge, completion evidence, voting, points, streaks, and group ranking in one place.

Motivation

Without a dedicated space, group progress becomes difficult to follow and motivation gradually disappears.

Web Application Justification

Why the tools students already use are not enough

PlayReal is a web application because it needs collaborative follow-up, statistics, evidence, voting, and frequent updates from several users at the same time.

WhatsApp / Instagram

Useful for communication, but evidence gets mixed with regular messages and there is no organized ranking or score history.

Spreadsheet

Scores can be stored, but someone has to maintain them manually and the experience is not designed around participation.

PlayReal

One place for challenges, evidence, voting, scores, streaks, and rankings that works directly from a browser.

The Solution

A simple flow from start to finish

PlayReal organizes each challenge into a clear flow that every group member can follow without confusion.

Target Users

Designed for small groups of students

PlayReal is designed for university students who want to stay motivated with habits such as reading, studying, exercising, drinking water, practicing a language, or completing creative challenges alongside friends or classmates.

Habit Challenges

Reading, studying, hydration, language practice, exercise, and other recurring habits.

Group Challenges

Creative activities and friendly competitions that encourage participation between friends.

User Stories

Core PlayReal interactions

Create a Private Group

As a user, I want to create a private group so that I can invite my friends and participate in challenges with them.

Check the Active Challenge

As a participant, I want to check the active challenge so that I know what I need to do and when I need to complete it.

Upload Evidence

As a participant, I want to upload a photo with a comment so that I can prove that I completed the challenge.

Vote for Evidence

As a participant, I want to vote for a submission so that I can help choose the best participation.

View the Ranking

As a participant, I want to view the group ranking so that I know my position and points.

Project Checklist

PlayReal project criteria

  • A real problem related to organizing challenges through chats and social media.
  • A specific target user: university students participating in challenges with friends.
  • A centralized solution for evidence, voting, scores, streaks, and ranking.
  • User stories written using the As a / I want / So that structure.
  • Responsive Tailwind implementation for mobile, tablet, and desktop.
  • Complete responsive Lo-Fi wireframes for the main PlayReal screens and their interface states.
